## ✨ Fitur

- 🧠 **AI Diagnosis** — Deteksi kondisi kandungan berdasarkan gejala
- 💬 **Konsultasi Interaktif** — Tanya jawab gejala layaknya dokter
- 📊 **Hasil Lengkap** — Diagnosa + persentase kemungkinan + rekomendasi
- 📖 **Basis Pengetahuan** — Ratusan rule dari pakar kandungan
- 👩‍⚕️ **Rekomendasi Dokter** — Saran tindak lanjut berdasarkan hasil
- 📱 **Responsive** — Bisa diakses dari HP maupun PC
- 🔐 **Data Privat** — Riwayat konsultasi tersimpan aman

---

## 🧠 Cara Kerja AI

```
Input Gejala → Forward Chaining → Rule Matching → Diagnosa + CF Score → Rekomendasi
```

Sistem menggunakan metode **Forward Chaining** dengan **Certainty Factor (CF)**:

| Nilai CF | Interpretasi |
|----------|-------------|
| 0.8 - 1.0 | Sangat Pasti |
| 0.6 - 0.8 | Pasti |
| 0.4 - 0.6 | Kemungkinan Besar |
| 0.2 - 0.4 | Mungkin |
| 0.0 - 0.2 | Tidak Yakin |

## 🚀 Quick Start

### Prerequisites
```bash
PHP >= 8.0
MySQL >= 8.0
Composer
```

### Installation

```bash
# Clone repo
git clone https://github.com/haza233/new_sistem_pakar_kandungan_be.git
cd new_sistem_pakar_kandungan_be

# Install dependencies
composer install

# Setup database
mysql -u root -p < database/schema.sql
mysql -u root -p nama_db < database/seeder.sql

# Setup environment
cp .env.example .env
php artisan key:generate  # jika Laravel

# Jalankan
php artisan serve
# atau
php -S localhost:8000
```

### Environment Variables
```env
DB_HOST=127.0.0.1
DB_DATABASE=sistem_pakar_kandungan
DB_USERNAME=root
DB_PASSWORD=yourpassword
```
